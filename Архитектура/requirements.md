# 1. Назначение

Разработать консольное приложение на Python для создания, просмотра и удаления заметок различных типов.

# 2. Типы заметок

|Тип|Необходимые данные|
|---|---|
|Обычная заметка|Название, содержание|
|Задача|Название, содержание, количество дней|
|Рецепт|Название, список шагов приготовления|
# 3. Функциональные требования

## 1. Управление заметками

|ID|Функциональное требование|Критерий приёмки|
|---|---|---|
|FR-01|Программа должна позволять создавать заметки.|Пользователь может создать заметку выбранного типа.|
|FR-02|Программа должна поддерживать три типа заметок: обычную заметку, задачу и рецепт.|Можно создать объект каждого из трёх типов.|
|FR-03|Программа должна позволять просматривать все существующие заметки.|Отображаются все заметки, находящиеся в коллекции.|
|FR-04|Программа должна позволять просматривать отдельную заметку по её ID.|По существующему ID выводится соответствующая заметка.|
|FR-05|Программа должна позволять просматривать отдельную заметку по названию.|По существующему названию выводится соответствующая заметка.|
|FR-06|Программа должна позволять удалять заметку по ID.|Выбранная заметка удаляется из коллекции.|
|FR-07|Программа должна позволять удалять заметку по названию.|Выбранная заметка удаляется из коллекции.|

## 2. Функциональность обычной заметки

|ID|Функциональное требование|Критерий приёмки|
|---|---|---|
|FR-08|Обычная заметка должна хранить название.|Название доступно после создания заметки.|
|FR-09|Обычная заметка должна хранить содержание.|Содержание доступно после создания заметки.|
|FR-10|Программа должна позволять выводить информацию об обычной заметке.|Выводятся её название и содержание.|

## 3. Функциональность задачи

|ID|Функциональное требование|Критерий приёмки|
|---|---|---|
|FR-11|Задача должна хранить название.|Название задачи доступно после создания.|
|FR-12|Задача должна хранить содержание.|Описание задачи доступно после создания.|
|FR-13|Задача должна хранить количество дней до срока выполнения.|У задачи сохраняется указанное количество дней.|
|FR-14|Программа должна позволять выводить информацию о задаче.|Выводятся название, содержание и количество дней.|
|FR-15|Программа должна позволять просматривать задачи в порядке возрастания количества оставшихся дней.|Сначала отображаются задачи с меньшим количеством оставшихся дней.|

## 4. Функциональность рецепта

|ID|Функциональное требование|Критерий приёмки|
|---|---|---|
|FR-16|Рецепт должен хранить название.|Название доступно после создания рецепта.|
|FR-17|Рецепт должен хранить список шагов приготовления.|Список шагов доступен после создания рецепта.|
|FR-18|Программа должна позволять выводить информацию о рецепте.|Выводятся название и все шаги приготовления в установленном порядке.|

## 5. Дополнительные сценарии обработки ошибок

Следующие сценарии предлагаются для повышения надёжности программы. Перед включением в окончательную спецификацию необходимо убедиться, что они не противоречат условиям лабораторной работы.

|ID|Сценарий|Ожидаемое поведение|
|---|---|---|
|FR-19|Пользователь ищет заметку по несуществующему ID.|Программа сообщает, что заметка не найдена.|
|FR-20|Пользователь ищет заметку по несуществующему названию.|Программа сообщает, что заметка не найдена.|
|FR-21|Пользователь удаляет несуществующую заметку.|Программа сообщает, что удалить заметку невозможно.|
|FR-22|В коллекции нет заметок.|Программа корректно сообщает об отсутствии заметок или выводит пустой список.|
|FR-23|Несколько задач имеют одинаковое количество оставшихся дней.|Все задачи отображаются; порядок между ними определяется выбранным правилом сортировки.|
|FR-24|Пользователь вводит некорректное количество дней.|Программа сообщает о некорректном вводе и не завершается аварийно.|

|NFR-03|Код должен быть отформатирован с помощью Black или эквивалентного инструмента.|Проверка форматирования подтверждает соответствие кода выбранному форматеру.|Обязательно по заданию|
|NFR-04|Код должен иметь понятную и последовательную структуру.|Назначение основных модулей, классов и методов можно определить по их именам и организации кода.|Рекомендация|
