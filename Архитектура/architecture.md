# Архитектура приложения

## 1. Общая структура

Приложение представляет собой консольную программу на Python для создания, просмотра и удаления заметок трёх типов: обычных заметок, задач и рецептов.

Архитектура разделена на несколько компонентов, каждый из которых отвечает за определённую часть работы приложения:

1. Модели заметок.
    
2. Менеджер заметок.
    
3. Репозиторий для хранения данных.
    
4. Консольный интерфейс.
    

Такое разделение позволяет не смешивать работу с данными, выполнение операций и взаимодействие с пользователем.

## 2. Модели заметок

Для представления заметок используется объектно-ориентированный подход с наследованием.

### Базовый класс `Note`

Абстрактный класс, содержащий общие атрибуты всех заметок:

- `id` — уникальный идентификатор;
    
- `title` — название заметки.
    

От него наследуются три класса:

- `TextNote` — обычная заметка, содержит текстовое содержимое (`content`).
    
- `Task` — задача, содержит текстовое содержимое (`content`) и количество дней до срока выполнения (`days_left`).
    
- `Recipe` — рецепт, содержит список шагов приготовления (`steps`).
    

Каждый объект заметки представляет собой отдельный экземпляр соответствующего класса.

## 3. Менеджер заметок — `NoteManager`

Класс отвечает за основные операции над заметками.

Основные методы:

- `create_note()` — создание заметки;
    
- `find_by_id()` — поиск по идентификатору;
    
- `find_by_title()` — поиск по названию;
    
- `delete_by_id()` — удаление по идентификатору;
    
- `delete_by_title()` — удаление по названию;
    
- `get_all_notes()` — получение всех заметок;
    
- `get_sorted_tasks()` — получение отсортированного списка задач.
    

Также менеджер отвечает за проверку уникальности названий и назначение идентификаторов.
